# 🎓 Student Management System

Live Link : https://student-management-system-12.netlify.app/

A React-based Student Management System designed to manage student records through a simple and user-friendly interface. This project demonstrates student data management, API integration, and navigation using React.

## 📌 Project Overview

The Student Management System helps users view and manage student information efficiently. It is developed using React and communicates with an API to retrieve and delete student records.

## ✨ Features

- 📋 **View Students** — Display student records in a structured table.
- 🗑️ **Delete Students** — Remove student records.
- 🔄 **API Integration** — Fetch student data from an API.
- ⚡ **React Hooks** — Manage application state and side effects using `useState` and `useEffect`.
- 🧭 **Navigation** — Navigate between pages using React Router.
- ⚠️ **Error Handling** — Handle API errors and display relevant feedback.
- 📱 **User-Friendly Interface** — Organize student information for easy viewing.

## 🛠️ Technologies Used

- **React.js** — Frontend library
- **JavaScript** — Application logic
- **React Router DOM** — Page navigation
- **HTML5** — Application structure
- **CSS3 / Bootstrap** — Styling
- **REST API** — Student data communication

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Prince-Nandoliya/React.git
   ```

2. Navigate to the project directory:

   ```bash
   cd React/student_management_system_Exam
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually:

   ```text
   http://localhost:5173
   ```

## ⚙️ Configuration

If the application uses a backend API, ensure that the API server is running and that the API URL is configured correctly in the relevant file under `src/Api/`.
